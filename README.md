1. Введение:
- Docker Compose (утилита для управления несколькими контейнерами).
- Конфигурация осуществляется через файл docker-compose.yml.

2. Настройка сервера:
- Подключитесь к серверу и выполните команду для обновления списка пакетов: ```sudo apt update```.
- Затем выполните команду для обновления всех установленных пакетов до их последних версий: ```sudo apt upgrade```.
- Чтобы установить Docker, воспользуйтесь инструкцией по установке с официального сайта: ```https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository```.
- Проверьте состояние файрвола с помощью команды: ```sudo ufw status```.
- Если файрвол отключен, активируйте его: ```sudo ufw enable```.
- Теперь откройте необходимые порты: ```sudo ufw allow 80/tcp``` - порт 80 для HTTP, ```sudo ufw allow 443/tcp``` - порт 443 для HTTPS, ```sudo ufw allow 22/tcp``` - порт 22 для SSH.
- Командой ```sudo ufw status``` проверьте чтобы данные порты были в статусе Allow.

3. Команды запуска локально:
- Выполните команду для клонирования репозитория: ```git clone https://github.com/DmitryPikov/DRF.git```.
- После того как код приложения скачан, необходимо запустить контейнеры с использованием Docker Compose.
- Базовая команда: ```docker-compose up```. Данная команда собирает образы (если нужно) и запускает все сервисы, описанные в файле.
- Фоновый запуск: ```docker-compose up -d```. Данная команда для запуска контейнеров в фоновом режиме, чтобы терминал остался свободным.
- Чтобы убедиться, что приложение работает, откройте браузер и перейдите по адресу ```http://localhost```.

4. Команды для запуска на сервере:
- Откройте терминал на сервере и выполните команду: ```cd /var/www```, где /var/www - это директория, куда вы хотите склонировать проект.
- Затем выполните команду для клонирования репозитория: ```git clone https://github.com/DmitryPikov/DRF.git```.
- После того как код приложения скачан, необходимо запустить контейнеры с использованием Docker Compose.
- Базовая команда: ```docker-compose up```. Данная команда собирает образы (если нужно) и запускает все сервисы, описанные в файле.
- Фоновый запуск: ```docker-compose up -d```. Данная команда для запуска контейнеров в фоновом режиме, чтобы терминал остался свободным.
